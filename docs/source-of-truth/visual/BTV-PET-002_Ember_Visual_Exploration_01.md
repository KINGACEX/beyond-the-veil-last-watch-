# BTV-PET-002 — Ember Visual Exploration 01

**Status:** PROPOSED VISUAL OPTIONS — NOT CANON / NOT APPROVED  
**Source:** Foundation #11 — Ember Companion Bible v1.0  
**Assets:** `assets/concepts/characters/BTV-PET-002_ember-visual-exploration-01.svg` and the generated three-option concept sheet shown in the project conversation.

## Canon constraints

- Ember is an original rare canid lineage; he is not a divine being, fantasy monster, or artificial/occult creation.
- He is a believable animal companion with natural animal behavior.
- Exact breed characteristics, coat, markings, facial structure, tail, proportions and size remain open.
- This visual exploration must not silently establish any of those details.

## Three proposed directions

| Option | Direction | Strength | Risk / question |
|---|---|---|---|
| A | Lean, alert, shorter coat | Agile tracker silhouette | May read too close to familiar shepherd-like breeds |
| B | Athletic, medium coat, distinct pattern | Balanced companion readability | Pattern may need simplification for mobile rendering |
| C | Sturdier frame, warm coat, thicker neck | Strong wilderness-partner presence | Must preserve believable canid anatomy and agility |

These are art-direction choices, not species or breed decisions. None is recommended as canon until checked against the full Ember Bible, existing references and the creator's intended look.

## Visual production notes

- Generated image sheet is an exploratory presentation, not a final model sheet.
- The accompanying SVG is a simple editable vector silhouette study.
- Neither asset is approved for animation, rigging, marketing or final game use.
- Next technical pass should select one silhouette direction, create front/side/three-quarter turnarounds, define scale beside Asher, and build an expression/ear/tail behavior sheet.
- No Ember image or model has been placed in the runtime project.
