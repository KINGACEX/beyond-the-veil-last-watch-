## Rules

- These assets are exploratory and do not alter canon.
- Keep source files editable and preserve older versions.
- Do not move concept assets into runtime folders until accepted and technically validated.
- Never use an unapproved reference candidate as the master character model.
- Record provenance, rights, and creator approval before external publication.
