# Companion Quality-of-Life Catalogue — Roblox Edition

**Status:** Creator-approved direction; individual options remain subject to balancing, UX review and companion/canon approval.  
**Applies to:** All selectable companions in the Roblox edition.  
**Principle:** Free players receive the complete companion experience. Premium options may reduce interface friction, improve personalisation or add presentation. They must not make the companion stronger or change mission outcomes.

## 1. Universal free quality baseline

These are product-quality requirements for every player, not monetised upgrades.

| ID | Feature | Expected behaviour | Priority |
|---|---|---|---|
| FQ-01 | Natural Follow | Companion follows at a sensible distance and avoids crowding the player | Must |
| FQ-02 | Stay / Hold | Companion stays at a commanded position until released or recalled | Must |
| FQ-03 | Regroup | Companion returns to the player through a safe, valid path | Must |
| FQ-04 | Obstacle Navigation | Companion avoids common obstacles and recovers from simple navigation failures | Must |
| FQ-05 | Safe Recall | Player can recover a stuck companion in approved contexts without losing progress | Must |
| FQ-06 | Context Awareness | Companion recognises valid interaction contexts and does not react nonsensically | Must |
| FQ-07 | Command Acknowledgement | Clear accepted, unavailable, in-progress and completed feedback | Must |
| FQ-08 | Companion Status | Basic current task, availability and condition are visible | Must |
| FQ-09 | Formation Positioning | Companion keeps a useful position during exploration and group movement | Should |
| FQ-10 | Basic Command Wheel | All essential commands are reachable with a simple touch-first interface | Must |
| FQ-11 | Reliable Recall | Companion can be called back when appropriate; no paid-only recovery | Must |
| FQ-12 | Persistence | Selected companion and earned unlocks save and restore correctly | Must |
| FQ-13 | Mobile Usability | Large touch targets, readable text, one-handed reach considered | Must |
| FQ-14 | Accessibility | Reduced effects, clear contrast and non-colour-only status signals | Should |
| FQ-15 | Multiplayer Consistency | Other players see coherent companion positions and actions | Must |
| FQ-16 | Interruptibility | Player can cancel or redirect a companion routine when safe and valid | Must |

## 2. Premium convenience catalogue

Premium features may save taps, organise controls, reduce repetitive menu navigation or improve presentation. The underlying command, action quality and world result remain identical.

| ID | Option | Premium convenience | Fairness condition |
|---|---|---|---|
| PQ-01 | Configurable Quick Wheel | Customise command positions and favourite shortcuts | Every core command remains accessible free |
| PQ-02 | Saved Command Layouts | Save alternate touch-control layouts | Layout only; no command power change |
| PQ-03 | Contextual Quick Action | One-tap shortcut to a command already available in the current context | Free players can still issue the same command through the standard menu |
| PQ-04 | Command Preset Slots | Save named non-combat command routines | Presets cannot execute combat combos or bypass mission steps |
| PQ-05 | One-Tap Regroup Shortcut | Place Regroup on a convenient quick-access control | Same response and result as the free command |
| PQ-06 | Expanded Status Panel | More detailed task and state presentation | No hidden clues, enemy detection or extra tactical information |
| PQ-07 | Personal Companion Profiles | Customise profile cards, labels and display themes | Cosmetic/presentation only |
| PQ-08 | Bonding Interaction Collection | Additional optional non-combat interactions and animations | No purchasable affection, loyalty, spiritual worth or gameplay buff |
| PQ-09 | Photo / Showcase Mode | Additional poses, framing and companion display options | Does not pause, expose or manipulate live multiplayer encounters |
| PQ-10 | Cosmetic Accessory Sets | Approved collars, harness details, markings or decorative pieces where canon permits | Preserve silhouette and recognisable identity |
| PQ-11 | Animation Presentation Sets | Alternative idle, rest, recall and command animations | Same command timing and result |
| PQ-12 | Audio Presentation Sets | Optional command acknowledgement sounds | Must not mask gameplay audio or give tactical information |
| PQ-13 | Companion UI Themes | Alternative interface layouts and visual themes | Readability and accessibility remain equivalent |
| PQ-14 | Routine Preset Library | Save more personal safe-area routines | No extra movement speed, pathfinding range or mission automation |
| PQ-15 | Favourite Companion Slots | Save preferred companions and loadouts for quick selection at safe hubs | Switching still follows shared cooldown/context rules |
| PQ-16 | Expanded Journal Presentation | Organise already-earned companion records and memories | No exclusive clues, evidence or story facts |
| PQ-17 | Companion Showcase Space | Optional personal display arrangement in a safe hub/quarters | No rewards, currency generation or combat effect |
| PQ-18 | Quick Status Filters | Filter the companion's visible status information | No extra detection or information unavailable to free players |

## 4. Universal quality rules

1. Premium is never required to make the companion responsive, reliable or enjoyable.
2. Never deliberately degrade free pathfinding, command response, interface clarity or recovery.
3. A premium shortcut may reduce the number of taps, but it must call the same server-validated command and produce the same result.
4. Do not sell extra damage, health, armour, speed, stealth, detection range, accuracy, cooldown reduction, loot, currency, XP or mission success probability.
5. Do not sell access to mission-critical evidence, objectives, locations or story outcomes.
6. No randomised paid companion rewards, eggs, crates, spins or loot boxes.
7. No purchase-based affection, loyalty, prayer outcomes, divine favour or spiritual status.
8. Every premium control must have a clear free alternative.
9. Companion selection and switching rules apply equally to free and premium players.
10. Premium UI must not interrupt gameplay with repeated purchase prompts.

## 5. Suggested product bundles

Avoid selling every small option separately. Use coherent bundles:

### A. Companion Bond & Presentation Pack
- Optional bonding interactions
- Approved cosmetic accessory collection
- Alternative idle/rest/photo animations
- Companion profile presentation

### B. Companion Command Convenience Pack
- Configurable quick wheel
- Saved command layouts
- Contextual quick-action shortcuts
- Additional safe-context preset slots
- Expanded status presentation

### C. Companion Collection Pack
- Approved cosmetic sets for multiple companions
- Profile cards and showcase themes
- Optional animation/audio presentation sets

All bundle contents must be listed clearly before purchase. Product IDs and Robux prices remain unset until separately approved.

## 6. Recommended first-release scope

**Free at launch:**
- FQ-01 through FQ-08;
- FQ-10 through FQ-13;
- FQ-16;
- each companion's full mission-required functional kit.

**Consider after usability testing:**
- FQ-09 and FQ-14;
- PQ-01, PQ-03, PQ-05, PQ-06 and PQ-11;
- one well-defined Companion Bond & Presentation Pack.

Do not implement every option at once. First test the free companion loop with real mobile controls, then identify actual interface friction before deciding which premium shortcuts provide value.

## 7. Acceptance tests

- A free player can issue every essential command without excessive navigation.
- Premium shortcuts use the same server-side command validation as free controls.
- Equivalent commands in equivalent contexts produce equivalent game-world outcomes.
- Premium presets cannot run in prohibited contexts or bypass mission objectives.
- No premium option reveals additional mission evidence or tactical information.
- The companion can be interrupted, recalled and recovered without a purchase.
- Companion state and ownership persist across rejoin.
- The full free interface remains clear and usable on low-end Android devices.
- Multiplayer players see consistent behaviour regardless of purchase status.
